# Quest Log

A personal app that helps you stay organized and do better in life by turning your to‑dos into quests with importance levels, XP, and levels.

## Features
- Gamified quest tracker
- XP, levels, and streaks
- Export / import quests as JSON
- AI helper (Anthropic API) for brainstorming and task breakdown
- Mobile‑friendly layout, dark theme
- PWA support (GitHub Pages ready)

## How to run
Open `index.html` in your browser. No build step required.

## API Key
Enter your Anthropic API key in the Settings screen. It is stored only in your browser's localStorage.

*Note: This is a personal project. Do not share your API key.*

## Roadmap

Quest Log is a quest log first, not a game. The goal is to help you organize your life and make it feel more rewarding, so the order of work is:

1. Get the core working: add quests, track them, and make the leveling and XP system solid. The quest log should be separate from the add-quest form and easy to use.

2. Make the gamification work well: importance levels, main and side quests, XP, levels, and streaks that actually motivate you to finish things.

3. Add rewards later, once the basics work. Current idea: a medieval pixel village or character, in the style of Kingdom Come, that looks better and grows as you level up. This is nice to have, not a priority.

Also planned: a local AI helper (Ollama) to sort quests, and phone support.
